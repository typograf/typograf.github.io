# Инструкции для работы с проектом

## Проект и команды

- Это статический сайт Typograf с интерфейсом на Preact и TypeScript 6. Используйте Node.js 24 или новее и npm с `package-lock.json`.
- Установка зависимостей: `npm ci`. Проверки: `npm test` (ESLint, TypeScript и Vitest). Сборка: `npm run build`.
- После изменений интерфейса или сборки проверяйте `npm test` и `npm run build`. Для ручной проверки откройте собранный сайт через локальный HTTP-сервер, например `python3 -m http.server 8000`.

## Структура и сборка

- `src/components/` содержит компоненты Preact. Папка и основной файл компонента называются в PascalCase; связанные CSS, SVG и тесты держите рядом. Общие функции размещайте в `src/helpers/`, переводы — в `src/i18n/`.
- `src/index.ts` подключает клиентские корни Preact к готовой разметке. `src/ssr.tsx` создаёт разметку при сборке. Сохраняйте совместимость первоначального HTML и гидратации, включая настройки из localStorage и параметры URL.
- `src/html/index.html` — исходный шаблон страницы. `tools/build-ssr.mjs` и `tools/index.mjs` создают корневой `index.html`, встраивая HTML, CSS и JavaScript. Сборка клиентского кода настроена в `rollup.config.mjs`; не добавляйте второй сборщик для этой задачи без необходимости.
- Корневой `index.html` отслеживается Git. Правьте шаблон и исходники, затем пересобирайте страницу. Если сборка изменила только временные значения `?n=` у ресурсов, не включайте эту разницу в коммит.
- Статья, заголовок, метаданные, canonical и ссылки в шаблоне должны оставаться доступными без выполнения JavaScript: сайт публикуется без отдельного SSR-сервера. При изменении SSR проверяйте `tools/ssr.test.mjs`.

## Поведение и безопасность

- Сохраняйте существующие ключи localStorage, формат hash-ссылок, работу настроек, локализации, трёх видов результата и действий редактора, если задача прямо не требует их изменения.
- Пользовательский HTML в предпросмотре проходит через DOMPurify перед `dangerouslySetInnerHTML`; diff экранирует текст. Не вставляйте пользовательские строки в HTML без безопасной обработки. При изменении этого пути обновляйте соответствующие тесты.
- Для новых обработчиков и эффектов Preact соблюдайте зависимости хуков и очищайте таймеры и подписки. Применяйте `useCallback` там, где нужна стабильная ссылка на функцию, а не механически для каждого обработчика.
